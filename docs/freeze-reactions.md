# 冻结状态与元素反应联动

冻结本身保存冰元素量，火 / 雷可分别触发融化 / 超导，不需要先重新挂冰附着。
反应次序为有效元素护盾 → 冻结（只判火 / 雷）→ 普通单位附着，一段攻击只走其中一条。

## 冻结量与控制

- 水 + 冰反应生成冻结：初始时长仍为 `min(消耗量 × 2.5, 8)` 秒，再计韧性。
- 初始冻结量为上限处理后的时长 / 2.5，最多 3.2U；直接技能冻结也由技能原始时长 / 2.5 生成冻结量。
- 韧性只缩短控制时长，不再重复削减初始冻结量；100% 韧性不创建冻结状态。
- 剩余量为 `初始冻结量 × (1 - elapsed / duration)`，自然衰减与控制倒计时一致。
- 消耗冻结量时等比例推进 elapsed，控制同步缩短。耗尽后同步移除 FreezeBuff，解除其暂停；其他眩晕等控制仍在时继续暂停。
- 所有 addFreezeBuff 来源统一择长，按计入韧性的新时长比较旧状态剩余时长；较短或相等的新冻结不替换旧状态。
- UI 悬停提示显示剩余冻结量和当前剩余时间。

## 火 / 雷交互

| 来袭 | 反应 | 冻结消耗 |
| --- | --- | --- |
| 火 | 融化 | `min(剩余冻结量, 来袭量 × 0.5)` |
| 雷 | 超导 | `min(剩余冻结量, 来袭量 × 1.0)` |

融化沿用普通单位反应的伤害倍率 `2 × emAmplify(攻击者精通)`，与护盾的“只增强盾耗”规则区分。
超导沿用已有范围冰伤和削甲效果。反应不另外消耗目标同时存在的普通附着。
同一击刚生成的冻结带派发身份，不能再被这一击的后续元素段反应；后续独立攻击可以连续触发，没有全局反应 CD。

示例（忽略攻击间隔的自然衰减，韧性为 0）：2U 冻结对应 5 秒控制。
被 2U 火攻击后消耗 1U，剩余 1U / 2.5 秒；被 2U 雷攻击则耗尽并解冻。

## 碎冰与表现

- 强攻击碎冰仍由护盾结算后的实际扣血判定，达到最大生命 15% 才触发；冰爆公式保留原规则。
- 火 / 雷已经耗尽冻结时，该状态不会再碎冰或生成冰爆。若反应后仍有冻结，且实际扣血达到阈值，仍可触发碎冰并清空剩余冻结。
- 碎冰移除冻结实例，也就清空它提供的冰元素量；0U 冰爆不再次附着或触发元素反应。
- 正常反应文字高度保持 70。同一次伤害事件同时碎冰时，反应文字改用 50，碎冰保持 70，避免表头重叠。

## 地图验收步骤

1. 通过 KKWE 运行当前打包地图，用圣骑士先水弹、再冰弹冻结敌方普通步兵。
2. 随后打火弹：应显示融化，普通伤害获得增幅，冻结量与剩余控制时间减少；量耗尽时解冻。
3. 重新冻结后打雷弹：应显示超导，并观察额外冰伤 / 削甲，冻结量减少或耗尽。
4. 另用达到碎冰阈值的攻击观察碎冰；有剩余冻结且同击触发融化 / 超导时，两类表头错开高度。
5. 检查眩晕仍在时消耗完冻结不会提前解除眩晕；检查元素盾优先反应时冻结量不会被同段重复消耗。
